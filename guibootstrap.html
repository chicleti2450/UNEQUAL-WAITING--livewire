Versão 5.3.2

O que é o Bootstrap?

Bootstrap é uma biblioteca com componentes prontos, responsivos e modernos. Ele facilita a criação de interfaces profissionais com pouco código.

Inclua em seu projeto:

Bootstrap CSS - Estilos prontos
Controla cores, layout, tipografia, tamanhos e compoentes visuais. 

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css"
rel="stylesheet">

Bootstrap JS - Funcionalidades Interativas
Necessário para navbar mobile, modais, dropdowns, carrossel, e qualquer recurso dinâmico. 

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"
></script>

Bootstrap Icons - Ícons Prontos
Bibliotecas com centenas de ícones modernos. 

<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.10.5/font/bootstrap-icons.css"
link rel="stylesheet">

Com isso, você já pode usar todos os componemtes do bootstrap.

Estrutura da Página

Organizando a Página (containers)

O que é? O container é a caixa principal da página. É onde todo o conteúdo fica organizado.

Para que serve? Ele centraliza e limita a largura do conteúdo, deixando a interface mais limpa e profissional.

Exemplo Visual:

Container Padrão
Container Full (100% de largura) 
<div class="container">Conteúdo<div>
<div class="container-fluid">Tela Inteira<div>

Criando layouts responsivos (Grid)

O que é? O sistema de Grid divide a página em linhas e colunas.

Para que serve? Permite criar layouts que se adaptam a qualquer tela.

Exemplo Visual:

col-6
col-6
<div class="row">
    <div class="col-6">A</div>
    <div class="col-6">B</div>
</div>

Margin e Padding no Bootstrap

Margin (m) controla o espaço externo do elemento.
Padding (p) controla o espaço interno.

Ambos seguem a mesma estrutura:

    m{lado}-{tamanho}
    p{lado}-{tamanho}
Lados possíveis
Letra Significado
t top (cima)
b bottom (baixo)
s start (esquerda)
e end (direita)
x esquerda e direita
y cima e baixo
(vazio) todos os lados
